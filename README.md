# Tejkumar Patel | Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript.

## Features
- Dark theme with orange accents
- Typing animation, scroll-reveal effects, and a responsive mobile menu
- Project cards generated from a data array in `public/script.js`
- Automated deployment with GitHub Actions and GitHub Pages

## Structure
- `public/` contains the website files (the only folder that gets published)
- `.github/workflows/` contains the CI/CD pipeline
